# E-Commerce Website (E-Shopper)

A full-stack e-commerce web application built using Django framework.

## Features
- User Registration, Login & Logout
- Product Listing with Search functionality
- Add, Edit, Update and Delete products (CRUD)
- Responsive UI using HTML, CSS and Bootstrap

## Tech Stack
- Backend: Python, Django
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Database: SQLite

## How to Run Locally
1. Clone the repository
   git clone https://github.com/vrunda-8321/E-COMMERECE-E-Shopper-Website.git

2. Install dependencies
   pip install -r requirements.txt

3. Run migrations
   python manage.py migrate

4. Start the server
   python manage.py runserver

5. Open in browser
   http://127.0.0.1:8000
